# AshtonWard Projects

This repository serves as the central index and issue tracker for my projects, homelab infrastructure, automation, experiments, and future ideas.

## Project Tracking

GitHub Issues in this repository are the primary location for tracking work across my repositories.

Issues are used for:

- Planned projects and features
- Infrastructure changes
- Research and evaluations
- Improvements to existing systems
- Bugs and problems
- Documentation work
- Future ideas

Labels identify the relevant area, type of work, priority, state, and repository.

Completed work remains available through closed issues, providing a history of projects and changes over time.

## Repositories

### AnsiblePlaybooks

Infrastructure-as-Code and automation for my homelab.

This repository contains the automation used to configure and manage systems across the environment, including:

- Ansible inventories
- Host and group configuration
- Reusable Ansible roles
- Proxmox VM provisioning
- Docker host deployment
- Security tooling deployment
- GitHub Actions workflows
- Supporting PowerShell and shell scripts

### Homelab-Documentation

Documentation and knowledge base for my homelab.

This repository contains:

- Installation and setup procedures
- Configuration notes
- Architecture documentation
- Networking documentation
- Troubleshooting notes
- Technical reference material
- Diagrams and attachments
- Notes maintained through Obsidian

## Repository Structure

The repositories serve different purposes:

```text
.github
└── Planning and issue tracking

AnsiblePlaybooks
└── Infrastructure automation and implementation

Homelab-Documentation
└── Documentation and technical knowledge
```

In general:

**Issues describe what needs to be done.**

**Implementation repositories contain the code and configuration.**

**Homelab-Documentation explains how the environment works and how it is configured.**

## About

These repositories document the continued development of my homelab and personal technical projects, with a focus on networking, infrastructure automation, systems administration, security, and self-hosted services.
